# input-assets/references

Reference material that helps modelling and data entry, for example:

- photographs of the building and signage,
- floor-directory lists or room-number tables supplied by the university,
- notes about verified floor heights, units and scale,
- style/branding references (university logo, colours) once official ones are provided.

Nothing here is read by the application at runtime.

Guidelines:

- Keep only material you are allowed to store. Do not add personal data, credentials or private architectural drawings (`*.dwg`, `*.dxf`, `*.blend` are git-ignored in the CAD/Blender folders; the same rule applies in spirit here).
- Check file sizes before committing; prefer links or notes over large binaries.
- Data copied from here into the database or `data/demo/` must be verified before it is marked as real (`is_demo = false`); never present sample values as real university information.

This folder currently contains no reference files.
